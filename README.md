## 🚀 Run Locally

### Prerequisites

- [Node.js](https://nodejs.org/) and npm
- [Vercel CLI](https://vercel.com/docs/cli) to run the serverless API routes locally

### Setup

    git clone https://github.com/saurabh-verma2/Portfolio.git
    cd Portfolio
    npm install

Add the environment variables listed below, then start the local Vercel development server:

    npx vercel dev

Open the local URL printed by the Vercel CLI in your browser.

---

## 🔐 Environment Variables

Configure these variables in a local environment file or in your Vercel project settings:

| Variable | Required | Description |
| --- | :---: | --- |
| `GEMINI_API_KEY` | For chatbot | API key used by the Gemini-powered assistant |
| `GMAIL_USER` | For contact form | Gmail account used to send messages |
| `GMAIL_APP_PASSWORD` | For contact form | Gmail app password used for SMTP authentication |
| `CONTACT_TO` | No | Destination address for contact messages; defaults to `GMAIL_USER` |

> 🔒 Keep credentials private. Never commit API keys, passwords, or files containing secrets.
